# The Systemic Depths

A standalone, mobile-first systemic roguelike built with Phaser 3, TypeScript, and Vite.

## Development status

The project is in prototype development. The current goal is to validate the offline solo turn engine and mobile-first PWA experience before expanding campaign content or online features.

## Local development

```bash
npm install
npm run test
npm run build
npm run dev
```

## Safety and scope

- No production deployment or release is authorized by this repository setup.
- Purchases and premium gating remain disabled during development.
- Online co-op is deferred until solo simulation and save/load behavior are validated.
